LLMs não pensam em palavras

No artigo, os números eram ilustrativos. Aqui eles vêm de um modelo de verdade: um GPT-2 de 124 milhões de parâmetros treinado em português, rodando inteiro no seu navegador. Digite uma frase e siga o caminho: tokens → vetores → atenção → probabilidades → próximo token.

O que os experimentos mediram

O modelo tem ~128 MB. Ele é baixado uma vez e fica guardado no cache do navegador. Nada do que você digita sai do seu computador.

Os tokens (etapa 1) já funcionam sem o modelo.
Etapa 1

Tokens: o modelo nunca vê letras

O tokenizador corta o texto em pedaços frequentes e troca cada um por um número (o ID). O "␣" é o espaço, que vira parte do token. Embaixo de cada ID estão os bytes (UTF-8) que ele representa.

Mesma frase, três tokenizadores, duas línguas

Cada modelo tem o próprio vocabulário. O GPT-2 original foi treinado em inglês e quebra o português em mais pedaços: mais tokens = mais custo e menos contexto.

Etapa 2

Embeddings: cada token vira um vetor de 768 números

Na entrada, o vetor de "banco" é sempre o mesmo, seja qual for a frase. Camada a camada, o contexto vai sendo somado a ele. Escolha a camada e veja os vetores de "banco" em frases de cada sentido se afastarem.

Etapa 3

Atenção: quem olha para quem

Pesos reais de atenção do modelo. Cada linha é um token "perguntando" e soma 100% entre os tokens anteriores. Acima da diagonal fica a máscara causal: nenhum token enxerga o que vem depois. Clique numa linha para ver as setas.

Etapa 4

Logits → softmax → próximo token

O último vetor é comparado com os 50.257 tokens do vocabulário: cada comparação dá um logit. Dividir pela temperatura e aplicar o softmax transforma tudo em probabilidades. Top-k e top-p cortam a cauda, e um sorteio com semente escolhe o token, que entra no contexto para a próxima rodada.

O sorteio

Os tokens que sobraram dividem a faixa de 0 a 1 conforme a probabilidade. Um número da semente cai em um deles.

–tokens que sobram após os cortes
–probabilidade que eles somavam
–tempo da rede (no seu navegador)
–entropia (bits): incerteza da escolha
